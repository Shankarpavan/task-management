# TaskFlow - Task Management System

Project and task management app built with React (Vite) and Tailwind CSS.

## Features
- Create projects and add team members
- Add tasks, assign them to members and set deadlines
- Kanban board (To do, In progress, In review, Done) with drag and drop
- Subtasks with progress count
- Deadline reminders (due soon and overdue)
- Activity history for every project
- Data is saved in the browser (localStorage)

## Run locally
```bash
npm install
npm run dev
```
Build for production: `npm run build`
